# Design language

The conversation board is a private teleprinter wire, not a SaaS dashboard.

## Keep

- One continuous transcript instead of message cards or floating panels.
- Warm paper for the conversation and near-black for the machine around it.
- Cobalt identifies Alice; carmine identifies Bob. Color is a routing signal, not decoration.
- Monospaced interface labels and a readable serif only for message bodies.
- Square geometry, thin rules, compact metadata, and explicit system states.
- Plain action labels such as `TRANSMETTRE`.

## Avoid

- Gradients, glow effects, glassmorphism, blurred backdrops, and gradient text.
- Pill badges, oversized corner radii, floating cards, and decorative icon tiles.
- Generic hero copy, feature grids, excessive whitespace, or animations on every element.
- Purple as a default accent and Inter as a default typeface.
- Romantic decoration that competes with the actual correspondence.

The romance should come from two distinct voices sharing one wire. It should not need hearts, slogans, or simulated sentiment to explain itself.
